# Theo Browne on Council

[Stop Searching For the Perfect Model, starting at 2:27](https://www.youtube.com/watch?v=TWoS5Nmyoc8&t=147s) · [Full transcript](https://2outube.com/watch?v=TWoS5Nmyoc8)

- [4:11](https://www.youtube.com/watch?v=TWoS5Nmyoc8&t=251s) · Council puts independent reviewers on the same work. Different model families can find issues the others miss.
- [8:43](https://www.youtube.com/watch?v=TWoS5Nmyoc8&t=523s) · Pick the minimum score for the task. Theo's `Council 9.5` example requires each blocking reviewer to give at least 9.5/10 before the round can satisfy the target.
- [16:34](https://www.youtube.com/watch?v=TWoS5Nmyoc8&t=994s) · Reviewers can inspect the working code and run checks, so their findings can rest on direct evidence.
- [20:35](https://www.youtube.com/watch?v=TWoS5Nmyoc8&t=1235s) · A user can define what reviewers score. Theo asks whether a change fits a specific person's request.
- [22:42](https://www.youtube.com/watch?v=TWoS5Nmyoc8&t=1362s) · Repeated rounds can consume quota and balloon the diff. Limit the rounds or stop when the reviews stop producing useful changes.
