---
name: html-taste
description: Develop the visual direction of an HTML explainer, visualization, or interactive piece when the brief calls for creative design, a reference the user likes, or a better treatment of an existing render.
---

Find the part of the material the reader came to see. Work with the actual names, values, images, or states. Give the most revealing detail enough space to be understood. A long label, a tie, or a missing observation can change which composition works.

When the direction is open, try different ways of reading the same content. A festival program could follow one listener's evening, with each act leading to the next. The same acts on a shared time axis reveal clashes between stages. Choose the composition that answers the reader's question.

Use a reference for a specific decision you can point to. A tightly cropped photograph might reveal wear on an object. An interaction might let the reader hear the instant an edit takes effect. Work that idea through the piece using its own subject and the user's visual direction. For Theo Browne's design experiments and places to look for examples, see [Theo's references](references/theo.md).

Judge the render at the size the reader will use. Cover the title for a moment. Which detail gives away the subject? If the piece could introduce almost anything, bring its strongest evidence forward. Check the important labels at a narrow width and try any interaction the explanation depends on. Compare the revision with the previous render using the same content. When the user likes one detail, preserve it in the next pass.
